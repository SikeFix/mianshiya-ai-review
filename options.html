语音输入

开口答题、AI 听完给点评，这是复习效率最高的用法。

🎙️ 浏览器内置识别
零配置、零成本、说完立刻出字。 但 Chrome 走 Google 服务器，国内通常连不上；Edge 走微软服务器，国内可直连。 缺点是识别结果没有标点。
☁️ 云端转写
录完整段音频再发给语音转写接口。准确率高、自带标点、长句更稳， 不挑网络环境。需要配一个转写服务（可以和对话用同一个 Key）。
默认 1200 毫秒。

对话行为

只在「模拟面试」和「追问」模式下生效，会加在提示词最前面。换个语气，复习的体感完全不一样。
越大越有上下文，也越费 token。
太长的答案会挤占上下文，默认 6000 字。

模式提示词 改完立刻生效，可以按自己的习惯调

可用占位符：{title} 会替换成题目，{reference} 会替换成页面上的参考答案。

保存到本地 题目、答案、对话存成 Markdown

一道题一个 .md 文件，存在浏览器下载目录下的一个子文件夹里。 存出来的是纯文本，可以直接拖进 Obsidian、Typora、VS Code 或者你自己的笔记库。

相对于浏览器的下载目录。想换位置就去 chrome://settings/downloads 改「下载位置」， 或者把它设成「每次询问」，每存一次自己选目录。

间隔复习 答得不好的题会自动回来找你

在面板上每答完一题，点一下「完全不会 / 有点模糊 / 记住了 / 太简单」自评一次。 每个选项对应不同的复习间隔，到期的题会重新冒出来 —— 攒着的题才有机会被翻出来看第二遍。

间隔是乘法递增的：评为「记住了」会按难度因子拉长（1 天 → 2.5 天 → 6 天……）， 评为「完全不会」会把间隔清零、10 分钟后再来，并降低这道题的难度因子， 让它之后涨得慢一些。单题最长间隔 180 天。

复习记录

每轮对话都会记在浏览器本地（chrome.storage.local），刷新页面、切题都不会丢。 这里可以一次性导出成一份汇总笔记。

按分类导出时，每一类会生成一个同名文件夹和一份汇总 md，方便整包拖进笔记库。

学习报告 哪块行、哪块不行，一眼看到

按标签和速记关键词两个维度把题目聚起来，算出每块知识的薄弱分， 再给出下一步该补哪里。数据全部来自你本机的复习记录。

总开关

五分钟上手

  1. 在「AI 方案」里选一个服务商，填上 API Key，点「测试连接」，看到绿字就成了。
  2. 打开任意一道题，比如 Redis 中如何实现分布式锁？，右下角会出现悬浮球。
  3. 点开悬浮球，选「🎤 模拟面试」，AI 会开始提问。按住麦克风开口答，说完停顿一下就自动提交。

常见问题

点麦克风提示「连不上浏览器语音识别服务」
这是国内 Chrome 的固有问题 —— 它的内置识别要用 Google 服务器。两个办法：换 Edge 浏览器（微软服务器国内可直连）， 或者到「语音」标签页把引擎切到「云端转写」。

提示「API Key 被拒绝」
检查 Key 有没有复制全（前后别带空格）、账户有没有欠费。有些服务商的 Key 需要先在后台开通对应模型。

提示「网络请求发不出去」
第一次用某个服务商时，Chrome 会弹窗问是否允许扩展访问该网站，必须点「允许」。如果当时点了拒绝， 回到「AI 方案」重新点一次「保存」会再弹一次。

抓不到答案 / 一直提示会员墙
完整答案在面试鸭是会员内容，插件只读你屏幕上已经显示出来的东西，不会去绕过会员墙。 这种情况下 AI 会用自己的知识来讲解和打分，右下角会标出来来源。

AI 回答被截断了
到「AI 方案」把「最大输出 token」调大。

隐私说明

  • API Key 只存在本机浏览器的 chrome.storage.local 里，不会同步到 Google 账号，也不经过任何中间服务器。
  • 只有你点击发送时，题目和对话内容才会直接发给你自己配置的那个 AI 服务商。
  • 录音只在本地处理，直接发给你配置的转写服务，不上传到别处。
  • 插件不会修改面试鸭的任何数据，也不会调用它需要会员权限的接口。
